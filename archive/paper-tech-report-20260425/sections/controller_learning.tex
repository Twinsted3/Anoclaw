\section{Controller-Level Verbalized Learning}
\label{sec:controller}

The AnomalyClaw ensemble combines a multi-turn Agent branch with a
single-pass Direct branch under a fixed $0.5{:}0.5$ blend. This
extracts a $+1.69$ pp macro AUROC gain on Qwen3.5-VL-27B
(Table~\ref{tab:main_results}) purely from \emph{ensemble diversity}
--- the two branches make systematically different errors, and
fixed-weight averaging already helps. This section asks whether a
learned controller, guided by a small verbalized rulebook, can beat
the fixed blend without collapsing the diversity gain that produces
it in the first place.

We answer with a controller agent that generalises the ensemble with a learning
switch. When \emph{learning is disabled}, the controller is byte-equivalent to
the ensemble --- identical two-branch execution, identical $0.5{:}0.5$
blend. When \emph{learning is enabled}, a Controller VLM consumes
the image, both branches' score--rationale pairs, and a per-domain
rulebook, and writes a final anomaly score. The rulebook carries two
layers of knowledge: (i) \emph{meta-rules} (routing) distilled from
dev-set cases where the two branches disagreed, and (ii)
\emph{domain rules} (content) reused verbatim from a prior reference-only
and oracle-grounded pilot (Appendix~\ref{app:rulebook_pilot}). We note
up-front that \emph{the controller is not training-free}: rule construction consumes
dev-set ground-truth labels. The total oracle budget is the $40$-item
dev split per domain ($480$ labels across $12$ domains); the
pilot's reused L2 corrective layer is drawn as a $K{=}10$ balanced
FN/FP subset of this same $40$-item pool, not additional oracle
exposure (\S\ref{ssec:ctrl_protocol}, Appendix~\ref{app:rulebook_pilot}).
At inference, no label is consulted. On Qwen3.5-VL-27B CrossDomainVAD-12
test ($n{=}1418$), the learning-enabled controller reaches macro $0.7539$,
a $+2.05$ pp gain over the passive baseline of $0.7333$ with $95\%$
stratified paired bootstrap CI $[+0.41, +3.67]$ and bootstrap sign
probability $\hat{p}(\Delta{>}0) = 0.995$.

\subsection{Architecture}
\label{ssec:ctrl_arch}

Let $A(x)$ and $B(x)$ denote the Agent and Direct branches evaluated
on a query item $x$. Each returns a scalar score in $[0, 1]$ and a
short textual rationale, so $A(x) = (s_A, r_A)$ and $B(x) = (s_B,
r_B)$.

\paragraph{the ensemble (no learning).} The ensemble score is a fixed linear
combination
\[
\hat{s}_{\mathrm{ens}}(x) \;=\; w_A\,s_A \,+\, w_B\,s_B, \qquad
w_A = w_B = \tfrac{1}{2}.
\]
This is the \S\ref{sec:experiments} Table~\ref{tab:main_results}
baseline. On Qwen3.5-VL-27B it achieves macro AUROC $0.732$
($+1.69$ pp over single-call Direct $0.714$).

\paragraph{the controller (learning-enabled).} A Controller VLM $C$ receives the
same reference and query images that each branch saw, plus the two
branch outputs and a retrieved rulebook excerpt $\mathcal{R}(x)$:
\[
\hat{s}_{\mathrm{the controller}}(x) \;=\; C\bigl(\mathrm{imgs}(x),\ (s_A, r_A),\ (s_B, r_B),\ \mathcal{R}(x)\bigr).
\]
$C$ is prompted to return a JSON object with \texttt{final\_score}
$\in [0,1]$, a categorical \texttt{trust} $\in\{A, B, \mathrm{blend}\}$
and a one-line reasoning trace. On any controller failure (parse
error, API error, missing branch) the item falls back to the ensemble
linear blend, preserving the $0.732$ floor. The Controller sees the
image so that its arbitration is grounded in visual evidence, not
purely a text routing layer.

\paragraph{Rulebook RAG.} At inference, the Controller never sees the
full per-domain rulebook. A metadata filter over
$(\mathrm{domain}, \mathrm{category})$ first restricts the rule pool
to rules matching the item's class (domain-wide rules always
admissible). Within the filtered pool rules are ranked by priority ---
meta-rules first (up to $3$), then invariants and corrective rules
(up to $4$ combined) --- and rendered as a short markdown block. The
injected payload is typically $60$--$120$ tokens per query.

\subsection{Learning protocol}
\label{ssec:ctrl_protocol}

The learning pipeline runs offline, once per domain. It is
\emph{semi-supervised}: the Agent and Direct branches themselves never
see labels, but rule construction consults the dev-set ground-truth
labels ($40$ per domain, $480$ total across $12$ domains). Specifically,
all $40$ labels are consumed to partition dev items by branch
agreement (Stage B), and the ground-truth label of each sampled
disagreement case is shown to the reflector VLM (Stage C). Domain
rules (Stage D) reuse the earlier pilot's L2 corrective artefact,
which was built from a $K{=}10$ balanced FN/FP sub-sample of the
\emph{same} $40$-item dev pool (Appendix~\ref{app:rulebook_pilot});
this is not an additional oracle exposure. At test time no label
is consulted.

\paragraph{Stage A --- Passive collection.} We evaluate the controller with
learning disabled (i.e., the passive ensemble) on each domain's $40$-item dev split,
recording per item the pair $(s_A, r_A, s_B, r_B)$ and the manifest
label $y$.

\paragraph{Stage B --- Disagreement partition.} Each item's two
branch scores are binarised at $0.5$ and compared to $y$. Items
decompose into four buckets: \emph{agree-correct}, \emph{agree-wrong},
\emph{disagree-A-wins} (Agent right, Direct wrong), and
\emph{disagree-B-wins} (Direct right, Agent wrong). Over the $12$
domains this yields $61$ A-wins + $80$ B-wins = $141$ disagreement
cases total (an average of $11.8$ per domain; min $7$, max $18$).
\emph{Agree-wrong} items are discarded: they carry no
branch-routing signal, and pilot runs showed that asking the
reflector to write ``both-miss'' rules produces vacuous generic
cautions.

\paragraph{Stage C --- Meta-rule reflection.} From each domain we
balance-sample up to $K{=}10$ cases ($K/2$ A-wins, $K/2$ B-wins;
deterministic, sorted by item id) and feed them in a single
multi-image prompt to a reflector VLM (Qwen3.5-VL-27B). The reflector
sees per case the query image, both branches' score--rationale pairs,
and the ground-truth label. (Reference images are omitted because
vLLM caps image count at $12$ per prompt; refs are implicitly
described by each branch's rationale.) The reflector is asked for
$1$--$3$ routing rules per side under three explicit constraints:
(i) each rule must name an \emph{observable} pattern in the
rationale or image, not merely cite the item id; (ii) no ``always
trust $X$'' rules; (iii) rules must be actionable at inference time
from what the Controller sees. All $12$ domains produced parseable
rule lists, yielding $2$--$3$ rules per side per domain.

\paragraph{Stage D --- Rule stacking.} For each domain we merge the
meta-rules with the domain rules from the reference-only + oracle
pilot: reference-only invariants (\texttt{invariant} tag, six types:
count, symmetry, spatial layout, colour palette, texture,
structural) and oracle-grounded cluster rules
(\texttt{corrective\_fn} / \texttt{corrective\_fp} tags). Each rule
carries $(\mathrm{type}, \mathrm{category}, \mathrm{text},
\mathrm{source\_items}, \mathrm{confidence})$ metadata. Per-domain
stacked rulebook sizes range from $10$ (D12 road safety) to $86$
(D1 MVTec-AD, many categories each contributing invariants).

\paragraph{Findings.}

\begin{enumerate}
\item \textbf{Controller arbitration beats fixed blend at $95\%$
significance.} The $+2.05$ pp macro gain has a paired bootstrap
CI of $[+0.41, +3.67]$ and bootstrap sign probability $\hat p(\Delta{>}0) =
0.995$. Gains are concentrated but not fabricated: of the $12$
domains, $8$ improve (four by at least $+2.5$ pp), three regress by
at most $3.3$ pp, and one (D11) is essentially neutral. The gain
magnitude is similar to the fixed-blend gain itself ($+1.69$ pp,
Table~\ref{tab:main_results}), yet cumulative --- the controller compounds on top
of the ensemble rather than replacing it.

\item \textbf{The $+13.4$ pp D7 LEVIR change-detection swing comes
from correct routing.} On remote-sensing change detection, the refutation agent
trajectory scores $0.606$ macro AUROC (systematic FP on seasonal
vegetation changes) while Direct scores $0.861$. The fixed blend
($0.754$) sits roughly halfway, partly collapsing Direct's signal.
The Controller (trust counts $24$ A / $55$ B / $19$ blend) correctly
leans on Direct, and lands at $0.888$ --- a higher AUROC than either
branch alone. D8 DermaMNIST is the same story on dermatology
(the controller $0.721$ vs blend $0.647$, $+7.4$ pp).

\item \textbf{Three regressions, each a known failure mode.}
D3 VisA ($-1.9$ pp): the Controller over-trusts Direct ($60$ B /
$120$ items) when the Agent's structural reasoning was already the
right signal. D9 BraTS ($-3.2$ pp): brain-MRI texture heuristics in
the rulebook push the Controller off-target; \textit{agree-wrong}
items dominate error here so the Controller has no routing signal
to learn from. D12 BDD+RA ($-1.9$ pp): the blend sits at $0.982$,
essentially at the ceiling --- any Controller-driven deviation has
negative expectation. These three cases bound the
honesty of our claim: the $+2.05$ pp macro gain is not uniform.

\item \textbf{Controller behaviour is domain-aware and
non-trivial.} Trust counts vary dramatically: D1 mostly keeps blend
($64/120$), D5 heavily trusts Direct ($64$), D10 heavily trusts
Agent ($53$). The Controller is not collapsing to a constant
preference. Controller JSON parse-failure rate is exactly $0$
across $1418$ items.

\item \textbf{Sensitivity to the refutation agent parse failures.} A non-trivial
$\sim 7\%$ of test items have a terminal the refutation agent-trajectory
\texttt{malformed JSON after retries} error (notably D7 $16/98$,
D8 $53/120$; see Limitations). On those items the refutation agent falls back to
$s_A{=}0.5$ and the Controller tends to \texttt{trust=B}. Dropping
those items and re-running the bootstrap on the clean subset
($n{=}1318$) gives macro $\Delta = +1.73$ pp, CI $[+0.07, +3.29]$,
$\hat p = 0.982$ --- the significant gain survives, but loses
$\sim 0.3$ pp relative to the full-set headline. The the controller story is
therefore partly ``Controller learns to arbitrate'' and partly
``Controller safely handles Agent failure''; both are useful
behaviours, but they should be distinguished.

\item \textbf{Rule \emph{content} carries the gain, not the mechanism
or the presence of text.} A branch-frozen four-regime Controller
ablation decomposes the $+2.05$ pp. With the refutation agent/Direct outputs cached and
only the Controller re-invoked: empty-rulebook is $-1.04$ pp (CI
$[-2.84, +0.50]$, $\hat p{=}0.111$); scrambled rules (each domain
seeing another domain's rulebook under a symmetric D$i{\leftrightarrow}$D$i{+}6$
pairing) are $-1.34$ pp (CI $[-3.04, +0.32]$, $\hat p{=}0.053$).
Crucially, \emph{scrambled rules are statistically indistinguishable
from no rules}: $-0.30$ pp, CI $[-1.55, +0.97]$, $\hat p{=}0.315$.
Correct rules beat the scrambled control significantly: meta-only
$+1.91$ pp over shuffled (CI $[+0.58, +3.26]$, $\hat p{=}0.996$); the
full stack $+3.39$ pp over shuffled (CI $[+1.87, +4.79]$, $\hat
p{=}1.000$). Both rule-layer increments --- routing $+1.62$ pp and
domain $+1.48$ pp --- are significant at $95\%$. We make the
targeted claim: \emph{domain-matched rule content is necessary for
the full macro gain and for content-dependent domains}. Under
shuffled rules, content-dependent domains regress sharply (D9 BraTS
$-13.5$ pp, D4 SDNET $-9.3$ pp, D3 VisA $-4.9$ pp), while
disagreement-driven domains (D7 LEVIR $+10.0$ pp, D8 DermaMNIST
$+4.2$ pp) can still win because the Controller exploits visible
the refutation agent$\leftrightarrow$Direct imbalance in the rationales alone --- this
cap on shuffled-rule harm is real, not a contradiction of the
content-reading claim: the Controller uses rules when they are
informative and falls back on rationale-based arbitration when they
are not.
Per-domain, this splits cleanly: on domains where specific
invariants or corrective rules pay off (D4 SDNET concrete cracks,
D7 LEVIR change, D8 DermaMNIST, D10 liver CT), full $>$ meta
because the Controller needs the domain-content layer to
adjudicate; on domains where the two branches are already close
(D1 MVTec, D3 VisA, D5 LOCO, D11 HyperKvasir), meta-only suffices
or is even slightly better (noise level). The worst meta-only
regression is D4 SDNET ($-4.0$ pp vs blend), where the L1
structural invariants about concrete cracks carry specific content
the Controller cannot reconstruct from routing rules alone. This
is how the full stack's $+2.05$ pp decomposes: the controller-
arbitration and meta-routing \emph{contributions} introduced in
this section are genuine but modest ($+0.63$ pp on their own); the
statistically significant part of the gain further depends on
reusing the domain-content layer produced by the earlier rulebook
pilot (Appendix~\ref{app:rulebook_pilot}).
\end{enumerate}

\subsection{Limitations}
\label{ssec:ctrl_limits}

Each AD-mode test item pays an extra VLM call (Controller), which
adds approximately $35$--$50\%$ wall-time over the ensemble depending on
domain. The learning procedure is semi-supervised: the $40$-item
dev label budget per domain is the single unified oracle cost.
Stage B--C meta-rule construction consumes all $40$ labels; the L2
corrective layer reused from the rulebook pilot is a $K{=}10$
balanced FN/FP sub-sample of these same $40$ items, not additional
oracle exposure. Only the reference-only L1 invariants are
genuinely label-free. The rulebook is fixed at training time;
online rule evolution from test feedback is future work.
\paragraph{Single-backbone evidence.}
All the controller results are on Qwen3.5-VL-27B only. We frame the controller
learning story as a \emph{case study on the backbone where the ensemble is
weakest} (Qwen3.5 the ensemble $\Delta=+1.69$ pp, $95\%$ CI touches zero in
Table~\ref{tab:main_results}); whether the $+2.05$ pp controller gain
transfers to GPT-5.4 and SeedVL remains open. A second-backbone
replication of the branch-frozen 5-way table is the obvious next
experiment.

\paragraph{Parse-failure accounting.}
We track three separate JSON parse rates:
(i) Controller: $0/1418$ failed across all test items.
(ii) Direct : $\le 1\%$, covered by existing -path retries.
(iii) Agent the refutation agent trajectory: a non-trivial $\sim\!7\%$ of test items
(notably D7 $16/98$ and D8 $53/120$) end with a terminal
\texttt{malformed JSON after retries} error. On those items the
the refutation agent branch defaults $the refutation agent\_score{=}0.5$, Direct's rationale is
passed through unchanged, and the Controller typically selects
\texttt{trust=B}. This is a valid robustness pathway --- the
Controller recovers from the refutation agent failures by leaning on Direct --- but
part of the $+2.05$ pp macro gain on D7/D8 is attributable to
\emph{downweighting broken Agent outputs}, not purely to learned
meta-routing. A variant that fixes the refutation agent's parse issues first (or
an oracle ablation that excludes items where the refutation agent errors) would
isolate the routing contribution more cleanly; we flag this as
future work.
\paragraph{Floor and failure modes.}
The the controller floor guarantee depends on the Controller's JSON being
parseable; when it is not we fall back tothe ensemble blend rather
than either branch alone (observed Controller parse-failure rate
on this run: $0\%$). Finally, the D9 regression flags a genuine
limitation of disagreement-based learning: when both branches are
predominantly wrong together, the Controller has no routing
signal to exploit.
